# Reaction GP

F1 출발 신호를 본뜬 반응속도 측정 게임입니다. 빨간불 5개가 켜지고, 무작위 시간이 지나면 초록불로 바뀝니다. 그 순간 최대한 빨리 클릭하세요.
N라운드 반응 시간의 **합계(ms)** 가 작을수록 순위가 높습니다.

- 빌드나 설치 없이 순수 HTML/CSS/JS로 동작합니다.
- 폰트와 에셋을 모두 로컬에 두어, 인터넷이 없는 행사장에서도 실행됩니다.

## 실행 방법

### 배포용: 설치 없이 실행 (Windows / Mac / Linux)

```bash
python3 build.py
```

`dist/`에 아래 파일이 만들어집니다. 실행 파일 빌드에는 [bun](https://bun.sh)이 필요합니다(빌드하는 PC에만 필요, 행사장 PC에는 필요 없음).

| 파일                                              | 대상                                  | YouTube BGM                                                  |
| ------------------------------------------------- | ------------------------------------- | ------------------------------------------------------------ |
| `reaction-gp-windows.exe`                         | Windows                               | 재생됨                                                       |
| `reaction-gp-mac-apple` / `reaction-gp-mac-intel` | Mac (M1 이후 / Intel)                 | 재생됨                                                       |
| `reaction-gp-linux`                               | Linux                                 | 재생됨                                                       |
| `reaction-gp.html`                                | 브라우저만 있으면 어디서나 (더블클릭) | **안 됨** (설정 화면에서 링크 칸이 숨겨지고 MP3 → 칩튠 재생) |

- 실행 파일을 더블클릭하면 게임 서버가 켜지고 브라우저가 <http://127.0.0.1:8123> 으로 열립니다. 함께 뜨는 창을 닫으면 종료됩니다.
- 폰트·배경이 모두 파일 안에 들어 있으니 해당 파일 하나만 옮기면 됩니다.
- Mac에서 "확인되지 않은 개발자" 경고가 뜨면 파일을 우클릭 → 열기 를 누르세요.
- 기록은 주소별로 저장됩니다. 실행 파일(`127.0.0.1:8123`), 개발용 서버(`localhost:8123`), HTML 파일은 기록을 공유하지 않으니 옮길 때는 F1 → JSON 내보내기/불러오기를 쓰세요.

### 로컬 서버용

```bash
python3 -m http.server 8123
```

브라우저(Chrome 권장)에서 <http://localhost:8123> 을 엽니다. YouTube BGM은 이 방식에서만 재생됩니다.

> 소스의 `index.html`을 더블클릭해서(`file://`) 열면 신호등 그래픽이 나오지 않습니다. 파일로 열 때는 `dist/reaction-gp.html`을 쓰세요.

처음 실행하면 **설정 화면**이 나옵니다. 대회 정보를 입력하고 Enter를 누르면 대기 화면(순위표)으로 넘어갑니다.
행사장에서는 F11로 전체화면을 켜 두는 것을 권장합니다.

### 온라인 공개용: GitHub Pages

`*.github.io` 주소로 열면 **공개 모드**로 동작합니다.

- 설정 화면 없이 바로 순위표(대기 화면)가 나옵니다. 기본 설정(3라운드, 랜덤 좌/우 끔)으로 고정되고 F1 관리자 화면은 열리지 않습니다.
- 순위는 `online.js`가 Firestore에 저장해 모든 방문자가 같은 순위표를 봅니다. 연결에 실패하면 각자 브라우저 메모리에만 남습니다.
- 온라인 관련 코드는 모두 `online.js`에 있고 공개 모드에서만 불러오므로, 행사장용 빌드(`dist/`)에는 들어가지 않습니다.
- 로컬에서 확인: <http://localhost:8123/?public>

**Firebase 설정 (처음 한 번)**

1. [Firebase 콘솔](https://console.firebase.google.com)에서 프로젝트를 만듭니다. 이때 **Google 애널리틱스 사용**을 켭니다(GA4).
2. 빌드 → **Firestore Database** → 데이터베이스 만들기 (프로덕션 모드).
3. Firestore → **규칙** 탭에 아래를 붙여 넣고 게시합니다. 읽기와 새 기록 추가만 허용하고 수정·삭제는 막습니다.

   ```
   rules_version = '2';
   service cloud.firestore {
     match /databases/{db}/documents {
       match /scores/{id} {
         allow read: if true;
         allow create: if request.resource.data.keys().hasOnly(['name', 'total', 'avg', 'times', 'ts', 'random'])
           && request.resource.data.name is string && request.resource.data.name.size() <= 10
           && request.resource.data.total is int && request.resource.data.total >= 0 && request.resource.data.total <= 9000
           && request.resource.data.times is list && request.resource.data.times.size() == 3;
       }
     }
   }
   ```

4. 프로젝트 설정 → 내 앱 → **웹 앱 추가** → 나오는 `firebaseConfig` 값을 `online.js` 위쪽 `FIREBASE`에 그대로 옮기고 커밋·푸시합니다.
   (이 값은 공개되어도 되는 값입니다. 접근 제어는 3번 규칙이 합니다.)
5. GA4: 페이지 조회는 자동, 게임 이벤트는 `game_start`, `game_finish`, `score_save`로 기록됩니다. Firebase 콘솔 → Analytics 또는 GA4에서 확인합니다.

> 기록은 브라우저에서 계산해 보내므로, 마음먹고 조작한 점수를 막을 수는 없습니다. 이상한 기록은 Firestore 콘솔에서 직접 지우세요.

## 게임 규칙

1. 대기 화면에서 **Enter**를 누르면 시작합니다.
2. 라운드마다 빨간불 5개가 켜진 뒤 무작위 시간(기본 1~4초)이 지나면 초록불로 바뀝니다.
3. 초록불이 켜지면 **좌클릭**합니다. 초록불이 켜진 순간부터 클릭까지 걸린 시간이 기록됩니다.
   - **랜덤 좌/우 모드**: 화면에 `◀ 왼쪽 클릭` 또는 `오른쪽 클릭 ▶`이 표시됩니다. 표시된 쪽 버튼을 눌러야 합니다.
4. 벌칙

   | 상황                               | 기록    |
   | ---------------------------------- | ------- |
   | 부정 출발 (초록불 전에 클릭)       | +1000ms |
   | 반대 버튼 (랜덤 모드)              | +1000ms |
   | 시간 초과 (3초 안에 클릭하지 않음) | +3000ms |

5. N라운드가 끝나면 결과 화면에 합계, 평균, 현재 순위, 반응속도 비교(T.M.I)가 나옵니다.
   이름(최대 10자)을 입력하고 Enter를 누르면 순위표에 저장됩니다.
   합계가 같으면 먼저 기록한 사람이 위에 옵니다.

## 조작키

| 키    | 화면         | 동작                                 |
| ----- | ------------ | ------------------------------------ |
| Enter | 설정         | 대회 시작 / 저장 후 닫기             |
| Enter | 대기(순위표) | 게임 시작                            |
| Enter | 결과         | 기록 저장                            |
| Esc   | 게임 중      | 중단 (기록 안 함)                    |
| Esc   | 결과         | 기록 저장하지 않고 대기 화면으로     |
| Esc   | 관리자       | 닫기                                 |
| R     | 게임 중      | 처음부터 다시 시작                   |
| F1    | 어디서나     | 관리자 화면 열기 (대회 진행 중일 때) |
| F11   | 어디서나     | 전체화면 켜기/끄기                   |

## 설정 항목

| 항목               | 기본값        | 범위 / 설명                        |
| ------------------ | ------------- | ---------------------------------- |
| 대회 이름          | REACTION GP   | 최대 24자                          |
| 측정 횟수 N        | 3             | 1~10. 대회가 시작되면 바꿀 수 없음 |
| 랜덤 좌/우 모드    | 끔            | 켜면 순위표에 🎲 표시              |
| BGM                | 켬            |                                    |
| 대기시간 최소/최대 | 1000 / 4000ms | 200~10000ms                        |
| 효과음 / BGM 볼륨  | 0.7 / 0.5     | 0~1                                |
| 순위표 표시 개수   | 10            | 5 / 10 / 15 / 20                   |

## 운영자 가이드

- **기록 저장 위치**: 기록은 브라우저 `localStorage`에 저장됩니다. 다른 브라우저나 다른 PC에서는 보이지 않습니다. 브라우저 데이터를 지우면 함께 사라집니다.
- **포트 주의**: 기록은 주소(`localhost:8123`)별로 따로 저장됩니다. 포트를 바꾸면 기존 기록이 보이지 않으니 항상 같은 포트로 실행하세요.
- **백업**: F1 → **JSON 내보내기**로 설정, 현재 대회, 지난 대회 기록을 한 파일로 받을 수 있습니다. 행사 중간중간 백업해 두세요.
- **복원 / PC 이동**: F1 → **JSON 불러오기**를 누르면 파일 내용으로 현재 데이터를 **덮어씁니다**.
- **새 대회**: F1 → **새 대회 시작**을 누르면 현재 대회가 종료됩니다. 종료된 대회 기록은 보관함에 남고 JSON 내보내기에 포함됩니다. 그 뒤 설정 화면으로 돌아갑니다.

## 파일 구조

```
index.html          화면 구성 (설정 / 순위표 / 플레이 / 결과)
game.js             게임 로직, 사운드(Web Audio), 저장, 키 조작
online.js           공개 모드 전용: Firestore 온라인 순위 + GA4 (Firebase 설정값)
style.css           스타일, 폰트 지정
assets/bg.webp      배경 픽셀아트 (신호등 불빛 색을 이 이미지에서 추출)
assets/fonts/       Press Start 2P, Galmuri11 폰트와 라이선스
build.py            배포 파일 빌드 (dist/: 단일 HTML + OS별 실행 파일)
server.js           실행 파일 진입점 (HTML 내장 localhost 서버)
```
